🍔 FAST FOOD BIG ICE
📌 Présentation du projet
FAST FOOD BIG ICE est un projet de création d'un système informatique destiné à la gestion d'un restaurant de restauration rapide.
🎯 Objectifs
Présenter les produits et les menus du restaurant.
Organiser les informations sur les produits.
Faciliter la gestion des commandes.
Améliorer l'organisation du fast-food.
🛠️ Technologies utilisées
HTML
CSS
JavaScript
